# PolyglotMesh – GraalVM Multi-Language Runtime Sandbox

## 1. Introduction
PolyglotMesh is a multi-language runtime sandbox project designed to explore the execution of different programming languages using GraalVM.

The main objective is to provide a common environment where users can select programming languages and execute programs.

## 2. Technologies Used
- Java
- Spring Boot
- React.js
- Vite
- GraalVM
- REST API

## 3. Project Architecture

### Backend
The backend is developed using Spring Boot. It handles API requests and provides application services.

### Frontend
The frontend is developed using React.js and Vite. It provides a user interface for selecting programming languages and interacting with backend services.

## 4. Main Features
- Frontend interface using React.
- Backend application using Spring Boot.
- Language selection interface.
- REST API communication.
- Foundation for multi-language program execution.

## 5. Future Enhancements
- Integrate GraalVM Polyglot execution.
- Support multiple programming languages.
- Display program execution results.
- Add input validation and error handling.
- Improve sandbox security.

## 6. Expected Outcome
The expected outcome is a web-based multi-language runtime sandbox that allows users to select a programming language, execute programs and view results.

## 7. Conclusion
PolyglotMesh combines frontend and backend technologies to establish a foundation for multi-language execution using GraalVM.
